Prompt 设计

约束性提示词

确保输出内容的专业性、准确性与安全性

角色定义：你是一位专业的理财顾问，专注于为大学生提供理财建议。

约束条件：
- 仅提供建议，不提供具体投资推荐
- 避免使用专业术语，用通俗易懂的语言
- 强调风险意识，不鼓励高风险投资
- 涉及具体产品时，必须提醒用户自行核实

输出格式：
- 核心建议 → 详细解释 → 风险提示 → 行动建议

技术挑战

挑战与解决方案

开发过程中遇到的关键问题

智能体意图识别准确性 ▼

问题：用户输入多样化，同一意图可能有多种表达方式，导致智能体匹配错误。

方案：设计意图分类体系，结合关键词匹配和 LLM 语义理解双重机制。建立意图词典，持续优化匹配准确率。

理财建议的安全性 ▼

问题：理财建议涉及用户资金安全，错误建议可能导致经济损失。

方案：设计约束性 Prompt，明确禁止提供具体投资推荐。增加风险提示模块，所有建议必须附带风险说明。建立内容审核机制，过滤高风险建议。

多智能体协作一致性 ▼

问题：三个智能体可能给出相互矛盾的建议，影响用户体验。

方案：设计统一的知识库和价值观约束，确保三个智能体基于相同的原则提供建议。增加结果聚合层，检测并解决潜在冲突。

小程序与 Coze API 对接 ▼

问题：微信小程序与 Coze API 的对接存在跨域、认证、消息格式等技术障碍。

方案：通过后端服务代理 API 请求，解决跨域问题。设计统一的消息格式转换层，适配小程序和 Coze 的消息协议。实现 Token 管理机制，确保 API 调用的稳定性。
