核心功能

功能模块

三大核心 Skills + 信息聚合推送

✅

/todo 任务管理

创建待办任务，支持自然语言解析时间。"明天下午3点提醒我开会" 自动解析为具体时间，集成 APScheduler 定时提醒。

⏰

/remind 定时提醒

设置定时提醒，支持一次性提醒和周期性提醒。集成 Redis 持久化存储，确保提醒不丢失。

📅

/deadline 截止追踪

追踪任务截止日期，自动汇总本周待办。支持按优先级排序，临近截止自动升级提醒频率。

📰

每日早报推送

自动汇总天气、日程、待办，每日早晨定时推送。集成外部 API 数据源，减少重复性人工操作。

📊

周报自动生成

汇总本周完成任务与下周计划，自动生成周报。支持自定义模板，一键导出为文档。

🔌

自定义 Skills 实现示例

# /todo 任务创建 Skill
@skill("/todo")
def create_todo(user_id: str, task: str, due_date: str = None):
    """创建待办任务，支持自然语言解析时间"""
    # "明天下午3点提醒我开会" → 解析为具体时间
    parsed_time = parse_natural_time(due_date)
    redis_client.hset(f"todo:{user_id}", task, parsed_time)
    return f"已创建待办：{task}，截止时间：{parsed_time}"

# /remind 定时提醒 Skill
@skill("/remind")
def set_reminder(user_id: str, message: str, time: str):
    """设置定时提醒，集成 APScheduler"""
    scheduler.add_job(
        send_reminder,
        'date',
        run_date=time,
        args=[user_id, message]
    )
    return f"已设置提醒：{message}，时间：{time}"

技术挑战

挑战与解决方案

开发过程中遇到的关键问题

自然语言时间解析 ▼

问题：用户输入"明天下午3点"、"下周五"、"3天后"等多样化时间表达，需要准确解析为具体时间。

方案：集成 NLP 时间解析库，结合正则匹配和语义理解，支持相对时间、绝对时间、模糊时间等多种表达方式。解析失败时回退到用户确认流程。

飞书消息格式适配 ▼

问题：飞书消息支持多种格式（文本、卡片、富文本），不同场景需要选择合适的格式。

方案：设计消息格式策略，简单回复用文本，结构化数据用卡片，长文本用富文本。通过装饰器模式统一消息发送接口。

定时任务可靠性 ▼

问题：APScheduler 默认内存存储，服务重启后定时任务丢失。

方案：将定时任务持久化到 Redis，服务启动时从 Redis 恢复任务。实现任务执行幂等性，防止重复执行。

多群聊上下文隔离 ▼

问题：机器人同时服务多个群聊，需要隔离不同群的上下文和数据。

方案：以 chat_id 作为隔离键，Redis Hash 存储各群独立的待办、提醒等数据。会话状态通过 user_id + chat_id 组合键管理。
