实践 案例

不只是说"我会用 AI"，而是展示具体怎么用、解决了什么问题

🗣️
Claude Code 全流程开发
驱动一个 6 模块 FastAPI 项目从零到发布
通过 Claude Code（ACP 协议）代理完成 日志溯源卫士智能体 的全部模块开发。从架构设计、策略工厂模式搭建、16 条攻击链规则编写，到前端 Vue3 SPA 页面、API 测试，整个项目接近完全由 Claude Code 编写代码。
Claude Code ACP FastAPI 全栈
🤖
Hermes Agent 日常开发助手
终端里的 AI 搭档，覆盖编码到运维
Hermes Agent 作为每日开发伴侣：用 patch 精确替换代码、terminal 执行命令、browser 测试前端页面、search_files 快速定位代码、memory 持久化项目上下文。编写 Custom Skills 记录常见工作流，下次直接复用。
Custom Skills 终端 Agent 持久记忆 工具链
🧠
LLM JSON 截断恢复
让 LLM 输出从来不崩的实战方案
在安全溯源项目中，LLM 返回 JSON 经常被截断。设计了 4 层恢复策略：直接解析 → 括号补全 → raw_decode 流式抽取 → 正则片段提取。从"10 次有 3 次崩"到"零失败"。这个方案已写成 Skill 供后续项目复用。
Prompt Engineering 容错 JSON 解析 鲁棒性
🔧
两阶段分析引擎设计
关键词 + LLM 混合，性能与智能兼得
不要每行日志都调 LLM——这是常识，但怎么设计降级策略不是。设计了两阶段引擎：关键词正则 毫秒级预过滤 → 命中即返回（零 API 成本）→ 漏报才走 一次 LLM 调用 分析全部日志。再加混合模式：两者同时跑，按 chain_name 去重合并。
混合架构 性能优化 关键词+LLM 降级策略
📋
Agent Skill 编写与管理
把重复工作固化为可复用的技能
每次解决一个复杂问题（5+ 工具调用），就把它写成 Skill——从测试工作流到浏览器自动化，从 CLI 代码审查到模块开发模板。Skill 是"可执行的记忆"：包含触发条件、步骤流程、常见陷阱、验证清单。下次遇到同样问题，Agent 自动加载。
Skill 系统 知识沉淀 可复用 自动化
🔄
多 Agent 协作
并行子任务 + 结果汇总
大型任务分解为并行子任务交给多个 Agent 同时执行。例如：同时审查 6 个模块、并行搜索多个技术方案、同时验证多端页面。每个子 Agent 独立上下文，最终汇总结果。理解 Agent 的 delegate_task 机制和上下文隔离。

Prompt 呈现

真实 Prompt 片段

从实际项目中摘取的 Prompt 设计——不是"咒语"，是可复用的工程实践

Claude Code 系统提示 · 结构化输出约束
输出要求：
- 每个攻击链必须包含：chain_name, description, risk_level, confidence
- confidence 取值范围 0.0-1.0，基于日志证据链的完整性
- 宽松判断：只要日志中存在至少 2 个阶段特征就应报告
- 输出必须是纯 JSON，不要用 markdown 包裹
- 已知攻击链候选（16 种）：ssh_brute_to_privesc, sql_injection_chain, ...
Hermes Agent Skill · 模块开发模板
触发条件：用户要求开发新的 FastAPI 模块
执行顺序：
1. 读取设计文档 → 提取接口规范
2. 读取 module 4 (script_gen) 作为风格参考
3. 先建 JSON 配置文件（零硬编码）
4. 按顺序创建 5 个文件：schemas → strategy → service → router → __init__
5. 拼接 app/main.py 注册路由
6. 验证：ast.parse() + json.load() + route inspection
