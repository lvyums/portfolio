开发 历程

从零到一的完整项目建设过程

架构设计与基础设施搭建
第 1-2 周
确定 FastAPI + Vue3 技术栈，设计模块化架构：策略工厂模式 + Pydantic 校验 + JSON 外部配置。搭建项目骨架，实现 LLM 工厂、上下文管理器、路由注册等基础设施。
▸六模块流水线架构设计 — 数据流单向解耦
▸工厂注册模式：StrategyFactory.register("name", Class) 零硬编码注册
核心模块开发（解析·采集·脚本·合规）
第 3-4 周
并行开发日志解析（6 种格式）、日志采集（多源接入）、脚本生成（正则/ES/Splunk）、合规审计（19 条等保规则），每个模块独立可测。
▸每条合规规则独立校验：等保要求的日志留存、敏感操作审计全覆盖
▸脚本生成三模式一键切换，后端生成 → 前端格式化展示
两阶段分析引擎：关键词 + LLM 混合
第 5 周
重写日志联合审查模块。16 条攻击链规则（SSH 爆破、SQL 注入、横向移动、数据窃取等），关键词预过滤毫秒级返回，LLM 语义降级兜底。避免为每条日志调 API，O(N) → O(1)。
▸关键词命中 → 零 API 延迟返回（纯本地正则）
▸关键词漏报 → 一次 LLM 调用分析全部日志
▸混合模式：关键词 + LLM 同时运行，结果按 chain_name 去重合并
// modules/log_correlate/service.py — 混合分析核心
keyword_chains = matcher.match(lines)          # 毫秒级关键词
if keyword_chains and not use_llm:
    return keyword_chains                        # 零 API 快路径

llm_result = await LLMChainAnalyzer.analyze(lines)  # 一次 LLM
return merge_chain_results(keyword_chains, llm_result)  # 去重+合并
