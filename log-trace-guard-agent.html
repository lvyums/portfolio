架构决策

三阶递进推理架构

能确定的事不猜，能查到的事不编，猜和编的事才交给 AI。三层架构各司其职，70% 的请求在 5ms 内完成，LLM 只处理最复杂的场景。

⚡

第一层：正则规则引擎

毫秒级 · 确定 · 零外部依赖

19 条 JSON 规则，纯本地正则运算，零 API 调用。日志格式识别、关键词预筛、攻击类型分类——确定性问题用正则解决。

⏱ 5ms 以内 🔍 19 条规则 💰 零成本 ≡ 零依赖
📚

第二层：RAG 知识库增强

精准检索 · 领域知识 · 可溯源

5 大知识库分片、259 条领域知识，ChromaDB 向量检索，Embedding 三级降级。合规审计需要比对等保 2.0 原文时，RAG 层确保回答有据可查。

📖 5 大知识库 📄 259 条知识 ✅ 可溯源 🔗 三级降级
🧠

第三层：大模型智能推理

语义理解 · 灰色地带 · 低成本运作

DeepSeek V4 Flash，10 秒超时自动降级，温度 0.1。只有攻击链时序推理、非标准日志解读等真正需要语义理解的场景才触发——前两层已过滤 90% 无关调用。

🧠 DeepSeek V4 ⏱ 10s 超时降级 🎯 仅复杂场景 📉 温度 0.1
⚡

第一层不用 LLM 的原因

日志格式识别是确定性问题，正则 5ms 搞定。每条都走 LLM 成本高、响应慢、还可能在安全场景里产生幻觉。JSON 规则可维护、可热加载，测试结果 100% 可预期。

📚

第二层需要 RAG 的原因

安全领域知识专业封闭，LLM 训练数据覆盖不足。等保 2.0、ISO 27001 等标准需要原文引用，向量检索比 LLM 参数更精准可靠。知识可独立更新，不影响业务代码。

🧠

第三层才用 LLM 的原因

攻击链时序推理、隐蔽模式识别、非标准日志解读需要语义理解。前两层已过滤 90% 调用，LLM 只处理必须的场景——成本可控，响应可预期。

代码质量

6 种设计模式治理复杂度

当代码开始变乱时就引入模式——每个模式解决一个真实痛点，不是为用而用。

🏭

工厂模式

Factory Pattern

新增一种日志解析器只需继承 BaseParser + 一行 register() 注册，上层路由和 Service 层零改动。6 种解析器统一由 LogParserFactory 按特征自动分发。

痛点：每加一种日志类型就要改路由层，代码散落难维护 → 改为工厂统一注册，新增只需一个文件 + 一行代码
🔄

策略模式

Strategy Pattern

6 种日志解析策略（SSH/Web/WAF/Firewall/DB/Traffic），统一实现 BaseParser 接口。攻击链检测也用同一思路：关键词快路径 → LLM 慢路径。

痛点：不同日志解析逻辑差异大，if-else 分支爆炸 → 每个策略独立维护，遵循开闭原则
📐

模板方法

Template Method

BaseParser 定义解析模板：can_parse(抽象) → parse_fields(抽象) → validate(统一校验)。子类只实现差异部分，消除 60% 重复代码。

痛点：每个解析器重复写"解析→校验→标记缺失字段"三步 → 公共校验收拢到父类
📦

上下文模式

Context Pattern

ContextManager 按 request_id 隔离请求上下文。6 个模块通过 context 共享状态，下游感知上游结果。TTL 自动过期，上限 500 条防内存泄漏。

痛点：模块间直接传参耦合度高，数据流混乱 → 统一上下文管理器，按 ID 隔离
⚡

两级管道

Two-Stage Pipeline

AttackChainMatcher 快慢双通道。Stage 1 纯关键词毫秒级预筛，Stage 2 置信度不足时降级到 LLM 语义增强。大多数攻击链在第一阶段搞定。

痛点：每条日志都调 LLM 检测攻击链，成本爆炸 → 本地正则在毫秒级完成预筛，按需降级
🔒

单例模式

Singleton Pattern

LogManager 全局唯一日志实例 + 正则关键词惰性缓存。首次匹配即编译并缓存，后续查询零开销。

痛点：全局资源被反复初始化；正则每次匹配都重新编译影响性能 → 全局单例 + 缓存
双形态设计

为什么同时做Web 和 CLI

Web 和 CLI 服务的不是同一群人。安全工程师白天看仪表盘，凌晨应急响应时只信任终端。两个都做，共享同一套核心引擎。

🌐

Web 可视化平台

FastAPI + Vue 3 SPA
  • 攻击链可视化—合规差距雷达图、溯源报告在线预览
  • 多人协作—团队成员共享，无需各自配置环境
  • 低门槛—HR、合规审计角色也能操作，零命令行基础
  • 攻防实训—12 个内置场景，浏览器内完成演练
22 个页面SPA 架构

  • CI/CD 集成—Jenkins/GitLab CI 中作为 pipeline 步骤
  • SSH 远程—无图形界面服务器，直接 ssh 运行分析
